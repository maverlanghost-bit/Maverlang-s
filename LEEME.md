# Cómo usar esta carpeta
Copia TODO su contenido a la raíz del repo (`Maverlang-stocks/`) antes de T01:
- `AGENTS.md` → contexto que Grok Build carga solo.
- `PROGRESO.md` → bitácora.
- `.gitignore`.
- `docs/` → DESIGN-SYSTEM, ARQUITECTURA, TAREAS, DISENO-REFERENCIAS, prompts/, styles/tokens.css, config/tickers.ts, supabase/0001_init.sql, .env.example.
La tarea T01 copia los archivos de `docs/config`, `docs/styles`, `docs/supabase` y `docs/.env.example` a su lugar definitivo.
Borra este LEEME.md después de copiar.
